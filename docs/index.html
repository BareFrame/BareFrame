Questions before you run it

Direct answers on anti-cheats, SmartScreen, hardware detection, and rolling back.

Is BareFrame safe with Riot Vanguard, FACEIT AC, EAC, and BattlEye?

Yes. BareFrame only modifies documented Windows settings (registry keys, power plans, services, NIC properties, and local game .ini files). It never installs kernel drivers, injects into games, or disables TPM 2.0 or Secure Boot. If you enable optional Bare-Metal Mode (VBS/HVCI off) and your specific Riot account receives a VAN:RESTRICTION prompt requiring HVCI, click Revert All or toggle Bare-Metal off and reboot.

How do I undo everything if I want stock Windows back?

Before touching any setting, BareFrame creates a Windows System Restore Point and exports timestamped registry and config backups to Documents\BareFrame\backups\. Clicking Revert All inside the app restores every Windows default cleanly.

Does it work on both Intel and AMD systems, or laptops?

Yes. BareFrame checks your CPU vendor, NVIDIA or AMD PCIe devices, installed RAM, motherboard vendor, and whether a battery is present. For example, laptops keep Windows Dynamic Tick at default to avoid hurting battery life, and RAM compression is only disabled on systems with 16 GB or more.

Why might Windows SmartScreen show a warning on download?

Windows flags new open-source executables until a signing certificate is active and reputation builds up. Our SignPath Foundation open-source code signing application is in progress. In the meantime, every release is built transparently via GitHub Actions from public source code that you can inspect line by line.

Does BareFrame stay running in the background after I optimize?

No. BareFrame does not install a startup service, tray monitor, or telemetry agent. Once you apply tweaks, close the window and the settings stay active natively in Windows with zero background CPU or RAM usage.
