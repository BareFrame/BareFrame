Common questions

          
Straight answers on anti-cheats, rolling back, hardware detection, and SmartScreen.

        


        

          

            
              Is BareFrame safe with Vanguard, FACEIT AC, EAC, and BattlEye?
              
            
            

              Yes. BareFrame only edits documented Windows settings (registry keys, power plans, services, network adapter properties, and local game config files). It never installs kernel drivers, touches game memory, or disables TPM 2.0 or Secure Boot. If you opt into Bare-Metal mode (VBS and HVCI off) and your specific account prompts for Memory Integrity, click Revert All or disable Bare-Metal mode and reboot.
            

          


          

            
              Can I undo every change cleanly?
              
            
            

              Before changing any setting, BareFrame creates a Windows System Restore Point and saves timestamped registry and config copies to Documents\BareFrame\backups\. Clicking Revert All inside the app restores Windows defaults cleanly.
            

          


          

            
              Does it adapt to Intel, AMD, and laptops?
              
            
            

              Yes. BareFrame checks your CPU, NVIDIA or AMD GPU, RAM capacity, motherboard vendor, and battery presence at runtime. Laptops keep default dynamic tick behavior to protect battery life, and memory compression is only disabled on systems with 16 GB of RAM or more.
            

          


          

            
              Why might Windows SmartScreen show a warning right now?
              
            
            

              Windows flags new open-source binaries until a code-signing certificate is active and reputation builds. Our SignPath Foundation open-source code-signing application is underway. Every release is compiled transparently by GitHub Actions directly from the public repository.
            

          


          

            
              Does BareFrame keep running in the background?
              
            
            

              No. BareFrame does not install a background service, startup task, or telemetry daemon. Once you apply tweaks, close the app and the Windows settings remain active with zero background CPU or RAM overhead.
