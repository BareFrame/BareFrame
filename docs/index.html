Questions

Clear answers before you install.

Is BareFrame safe with Riot Vanguard, FACEIT, EAC, and BattlEye?

Yes. BareFrame changes only documented Windows settings (registry, power plans, services, NIC properties, and user game configs). It never touches TPM 2.0, Secure Boot, game memory, or anti-cheat drivers.

Can I undo everything cleanly?

Yes. Every optimization run creates a Windows System Restore Point and saves backups to Documents\BareFrame\backups\. Clicking Revert All restores every setting back to stock Windows defaults.

Does it work on both Intel and AMD PCs?

Yes. BareFrame automatically detects your CPU, GPU (NVIDIA or AMD), RAM size, desktop vs. laptop battery state, and motherboard vendor — only applying optimizations that are safe and beneficial for your exact hardware.

Why is BareFrame 100% free?

Gamers shouldn't have to pay for closed-source tweak packs. BareFrame is MIT open-source so anyone can inspect every line of code, verify it's safe, and optionally leave a tip on Ko-fi if it boosts their frames.
